WynnOverhaul animations

Put .yml files in this folder to change or add weapon, spell, gathering and body animations.
Files here are layered over the defaults that ship inside the mod, so you only need to include what you change.

Changes apply while the game runs. The folder is checked once a second.
/owanim reload   reloads the files now and reports mistakes
/owanim folder   prints the path of this folder

The default files are in the mod jar under assets/wynnoverhaul/animations/ and are the best examples to copy from.
The full format is documented at https://github.com/Opalinium/WynnOverhaul/blob/main/docs/animations.md
